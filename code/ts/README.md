# ts

To install dependencies:

```bash
bun install
```

To run:

```bash
bun run index.ts
```

This project was created using `bun init` in bun v1.3.5. [Bun](https://bun.com) is a fast all-in-one JavaScript runtime.

# Evals

Phoenix is used for experiment runs + tracing.

Run evals:

- `bun evals/mcq/mcq.eval.ts`
- `bun evals/mcq/mcq_rag.eval.ts`
- `bun evals/navreas/navreas.eval.ts`
- `bun evals/navreas/navreas_rag.eval.ts`
- `bun evals/pei2024/pei2024.eval.ts`
- `bun evals/pei2024/rag.eval.ts`
